# Пример темы: Производная функции

**Определение (уровень A).** Производная \(f'(x)\) функции \(f(x)\) в точке \(x\) — это *предел мгновенной скорости изменения функции*, то есть 
\[
f'(x)=\lim_{h\to0}\frac{f(x+h)-f(x)}{h}.
\]
Это число показывает, насколько резко меняется \(f\) около точки \(x\). Геометрически \(f'(x)\) — тангенс угла наклона касательной к графику \(y=f(x)\).  

**Почему так (уровень B).** Средняя скорость на отрезке \([x,x+h]\) равна \(\frac{f(x+h)-f(x)}{h}\). Чтобы получить мгновенную скорость, надо брать предел при \(h\to0\). Для примера \(f(x)=x^2\):
\[
\frac{(x+h)^2 - x^2}{h} = \frac{x^2 +2xh + h^2 - x^2}{h} = 2x + h.
\]
При \(h\to0\) остаётся \(2x\), значит \((x^2)'=2x\).  

**Базовые правила:**

| \(f(x)\)            | \(f'(x)\)            |
|---------------------|----------------------|
| \(c\) (константа)  | \(0\)                |
| \(x^n\)            | \(n x^{n-1}\)        |
| \(e^x\)            | \(e^x\)              |
| \(a^x\)            | \(a^x \ln a\)        |
| \(\ln x\)          | \(1/x\)              |
| \(\sin x\)         | \(\cos x\)           |
| \(\cos x\)         | \(-\sin x\)          |
| \(\tan x\)         | \(\sec^2 x\)         |
| \(\arcsin x\)      | \(\frac{1}{\sqrt{1-x^2}}\) |
| \(\operatorname{arccos} x\) | \(-\frac{1}{\sqrt{1-x^2}}\) |

**Правила дифференцирования:**

- **Сумма:** \((f+g)' = f' + g'\).  
- **Произведение:** \((f g)' = f' g + f g'\).  
- **Частное:** \(\left(\frac{f}{g}\right)' = \frac{f' g - f g'}{g^2}\).  
- **Цепное:** \(\frac{d}{dx} f(g(x)) = f'(g(x)) \cdot g'(x)\).

**Пример средней сложности.** Пусть  
\[
f(x) = \frac{x^2 \sin x}{e^x} + \ln(x^2+1).
\]  
Продифференцируем по правилу частного и суммы:

1. \(\frac{d}{dx}\bigl(\frac{x^2 \sin x}{e^x}\bigr)\):  
   \[
   \frac{(2x \sin x + x^2 \cos x)e^x - x^2\sin x\cdot e^x}{e^{2x}}
   = \frac{(2x\sin x + x^2 \cos x - x^2\sin x)e^x}{e^{2x}} 
   = \frac{(2x\sin x + x^2(\cos x - \sin x))}{e^x}.
   \]
2. \(\frac{d}{dx}\ln(x^2+1) = \frac{2x}{x^2+1}.\)

Итого 
\[
f'(x)
= \frac{(2x\sin x + x^2(\cos x - \sin x))}{e^x} + \frac{2x}{x^2+1}.
\]

**Контрольные вопросы.** (с ответами кратко)

1. **Почему определение производной даёт мгновенную скорость?**  
   *Ответ:* потому что средняя скорость на малом отрезке \([x,x+h]\) есть \((f(x+h)-f(x))/h\). При \(h\to0\) этот предел — мгновенная скорость.

2. **Что означает геометрически \(f'(x)=0\)?**  
   *Ответ:* касательная к графику горизонтальна, экстремум или плоский участок.

3. **Откуда появилось \(n\) в производной \(x^n\to n x^{n-1}\)?**  
   *Ответ:* это коэффициент биномиального разложения \((x+h)^n = x^n + n x^{n-1}h + \dots\).

4. **Почему производная произведения даёт сумму двух членов?**  
   *Ответ:* т.к. \(\frac{d}{dx}(fg) = \lim (f(x+h)g(x+h)-f(x)g(x))/h\), раскрытие разности даёт две части: \(f'(x)g(x) + f(x)g'(x)\).

5. **Зачем нужен фактор \(g'(x)\) при дифференцировании \(f(g(x))\)?**  
   *Ответ:* это правило цепочки: изменение \(x\) влияет через \(g\), поэтому надо умножить на скорость изменения \(g\).

6. **Почему \(\frac{d}{dx}e^x = e^x\)?**  
   *Ответ:* экспонента — единственная функция, у которой средняя скорость изменения равна самой функции.

7. **Почему \(\frac{d}{dx}\ln x = 1/x\)?**  
   *Ответ:* обратная функция к \(e^x\): можно взять \(y=\ln x \iff x=e^y\), тогда \(\frac{dx}{dy} = e^y = x\), из обратных функций получаем \(\frac{dy}{dx}=1/(dx/dy)=1/x\).

8. **Как ведёт себя \(\frac{f(x+h)-f(x)}{h}\), если \(f\) не дифференцируема?**  
   *Ответ:* предел может не существовать (например, для угловой функции). Наличие предела означает дифференцируемость.

9. **Может ли функция быть непрерывной, но не иметь производной?**  
   *Ответ:* Да. Пример: \(f(x)=|x|\) непрерывна, но не имеет конечной производной в \(x=0\).

10. **Всегда ли наличие производной гарантирует непрерывность производной?**  
    *Ответ:* Нет. Пример: \(f(x)=x^2\sin(1/x)\) при \(x\neq0\), \(f(0)=0\). f'(x) существует, но не является непрерывным в \(0\).

# Пример темы: Градиент и дивергенция

**Определение.** Градиент \(\nabla f\) функции \(f(x,y,z)\) — это вектор из частных производных: 
\[
\nabla f = \Bigl(\frac{\partial f}{\partial x},\,\frac{\partial f}{\partial y},\,\frac{\partial f}{\partial z}\Bigr).
\]
Он указывает направление наиболее быстрого возрастания функции. Дивергенция \(\nabla\cdot \mathbf{F}\) для векторного поля \(\mathbf{F}(x,y,z)\) — это скаляр \(\partial_xF_x + \partial_yF_y + \partial_zF_z\), измеряющий «расходимость» поля (насколько из точки «вытекает» поток). 

**Интуиция.** Градиент похож на многомерную производную. Для \(f(x,y)\) он указывает, куда двигаться, чтобы \(f\) росла быстрее всего. Дивергенция — общее расширение/сжатие вектора поля. Ротор (curl) можно упомянуть: \(\nabla\times \mathbf{F} = (\partial_y F_z - \partial_z F_y,\;\dots)\) — мера «кручения» поля.

**Правила/таблица.**
- \(\nabla(f+g) = \nabla f + \nabla g\).  
- \(\nabla(fg) = f\nabla g + g\nabla f\) (фактор-правило, как дифференцирование).  
- \(\nabla\cdot(\nabla f) = \nabla^2 f\) (лапласиан).  
- \(\nabla\times(\nabla f) = 0\) (ротор градиента равен нулю).  

**Пример.** Пусть \(f(x,y,z)=x^2y + yz\). Тогда
\[
\nabla f = \Bigl(\partial_x(x^2y+yz),\;\partial_y(x^2y+yz),\;\partial_z(x^2y+yz)\Bigr)
= (2xy,\;x^2 + z,\;y).
\]
Для векторного поля \(\mathbf{F}=(xy,\,e^z,\,\sin(xy))\), дивергенция:
\[
\nabla\cdot \mathbf{F} = \partial_x(xy) + \partial_y(e^z) + \partial_z(\sin(xy)) = y + 0 + 0 = y.
\]

**Контрольные вопросы.**

1. **Что показывает направление градиента?**  
   *Ответ:* направление наискорейшего возрастания функции.

2. **Почему \(\nabla f\) — вектор?**  
   *Ответ:* потому что в каждой координате мерим скорость изменения по этой координате.

3. **Связан ли градиент с производной функции по нескольким переменным?**  
   *Ответ:* да, это вектор из частных производных (набор всех «деривативов»).

4. **Почему \(\nabla \times \nabla f = 0\)?**  
   *Ответ:* поскольку смешанные вторые производные равны (при гладкости), ротор градиента «аннулируется» (круговорот нет).

5. **Что означает \(\nabla \cdot \mathbf{F} = 0\)?**  
   *Ответ:* поле соленоидальное (источник/сток отсутствует, например магнитное поле без магнитных зарядов).

6. **Как вычислить \(\nabla \cdot (\alpha \mathbf{F})\) для константы \(\alpha\)?**  
   *Ответ:* просто \(\alpha \nabla \cdot \mathbf{F}\).

7. **Достаточно ли, что \(\nabla \cdot \mathbf{F}=0\) для того, чтобы существовал векторный потенциал?**  
   *Ответ:* локально да (теорема Стокса/Гельмгольца), но требует топологической проверки для глобального существования.

8. **Дайте геометрический смысл дивергенции «точно» в точке.**  
   *Ответ:* скорость изменения объёма бесконечно малой частицы жидкости при течении поля \(\mathbf{F}\).

9. **Что такое лапласиан \(\nabla^2 f\)?**  
   *Ответ:* дивергенция градиента, мера того, насколько \(f\) отличается от «среднего» соседних значений (используется в уравнениях типа Лапласа \(\nabla^2 f=0\)).

10. **Почему дивергенция линейна?**  
    *Ответ:* из линейности частных производных.

# Пример темы: Ранг матрицы и определитель

**Определение ранга.** Ранг матрицы \(A\) — максимальное число линейно независимых строк (или столбцов). Он показывает «размерность образа» преобразования \(A\) (сколько независимых направлений оно растягивает). Если \(\operatorname{rank}(A)=n\), то матрица «полностью ранжирована», иначе есть зависимость.  

**Определитель.** Для квадратной матрицы \(\det(A)\) — скаляр, характеризующий во сколько раз она меняет ориентированный объём при преобразовании пространства. Например, для \(2\times2\):
\[
\det\begin{pmatrix}a&b\\c&d\end{pmatrix} = ad - bc.
\]
Если \(\det(A)=0\), то \(\operatorname{rank}(A)<n\) (матрица вырожденная).  

**Интуиция.** Ранг показывает «насколько много» информации в матрице. Если все строки линейно зависимы, ранг=1 (или 0). Если ранг = размерность, матрица обратима. Определитель ≠0 как раз эквивалентно полной независимости.

**Таблица свойств:**

- \(\operatorname{rank}(A+B) \le \operatorname{rank}A + \operatorname{rank}B\).  
- \(\operatorname{rank}(AB) \le \min(\operatorname{rank}A,\operatorname{rank}B)\).  
- \(\operatorname{rank}(A)= \operatorname{rank}(A^T)\).  
- \(\det(AB) = \det(A)\det(B)\).  
- \(\det(A^T)=\det(A)\).  
- Если \(A\) невырождена (\(\det\neq0\)), то \(\operatorname{rank}(A)=n\).

**Пример.**  
\[
A=\begin{pmatrix}
1&2\\
2&4
\end{pmatrix}.
\]
Вторая строка = \(2 \times\) первой. Поэтому \(\operatorname{rank}(A)=1\). 
\(\det(A) = 1\cdot4 - 2\cdot2 = 0\), что согласуется (нет обратимости, ранг<2).  
Если \(B=\begin{pmatrix}2&0\\0&3\end{pmatrix}\), то \(\det(B)=6\) (растягивает площадь в 6 раз), и \(\operatorname{rank}(B)=2\).

**Контрольные вопросы.**

1. **Как ранг связан с решением системы \(Ax=b\)?**  
   *Ответ:* Если \(\operatorname{rank}(A)=\operatorname{rank}([A|b])\), то решение есть; если <n, бесконечно много решений (если согласована), если =n (полный ранг), то решение единственно при обратимости.

2. **Что означает \(\det(A)=0\)?**  
   *Ответ:* матрица сингулярная, есть линейная зависимость строк/столбцов, обратной нет.

3. **Как вычислить ранг на примере?**  
   *Ответ:* приведением к ступенчатому виду (метод Гаусса), счётом ненулевых строк.

4. **Почему \(\det(AB)=\det(A)\det(B)\)?**  
   *Ответ:* геометрически: сначала \(B\) растягивает объём на \(\det(B)\) раз, потом \(A\) — ещё на \(\det(A)\). Алгебраически выводится через свойство перестановок в определителе.

5. **Можно ли ранг понизить операциями над строками?**  
   *Ответ:* Ранг сохраняется при элементарных операциях (сложение строк, умножение на скаляр не влечёт изменения ранга).

6. **Почему ранг(A)=ранг(Aᵀ)?**  
   *Ответ:* число линейно независимых строк равно числу линейно независимых столбцов.

7. **Связь ранга и собственных чисел?**  
   *Ответ:* если матрица \(n\times n\) невырождена, у неё \(n\) ненулевых собственных чисел (детерминант = их произведение). Если ранг < n, то хотя бы одно с.ч. нулевое.

8. **Пример матрицы ранга 1.**  
   *Ответ:* любая матрица вида \(uv^T\) (внешнее произведение вектора строки на столбец) имеет ранг 1, если \(u,v\neq0\).

9. **Ранг и размерность образа линейного отображения.**  
   *Ответ:* ранг равен размерности подпространства, в которое отображает линейный оператор матрица.

10. **Почему ранг важен в вычислениях (например, МНК-регрессии)?**  
    *Ответ:* для решения нормальных уравнений \(X^TX\beta=X^TY\) нужна невырожденность \(X^TX\) (ранг = число признаков); иначе оценки не единственны.

# Краткий обзор других тем

*Из-за ограничения объёма здесь приведены лишь образцы полного изложения. В полном справочнике каждую тему нужно раскрыть подобным образом.*

- **Функции и предельный переход:** определение предела и непрерывности, $\varepsilon$–$\delta$ формализм; односторонние пределы, важность непрерывности. Примеры: $\lim_{x\to0}\frac{\sin x}{x}=1$.

- **Интеграл:** определение через предел сумм (Риман), основные правила интегрирования, таблицы и примеры. Теорема о среднем значении.

- **Ряды и разложения:** сходимость рядов, тесты Дирихле/Абеля, степенные ряды, радиус сходимости, ряд Тейлора, примеры.

- **Линейные ОДУ:** однородные/неоднородные, метод вариации параметров, примеры (затухающие колебания, рост населения).

- **Теория вероятностей:** случайные величины, законы распределения, Математическое ожидание, дисперсия, независимость, формула полной вероятности, центральные пределы.

- **Статистика:** оценка параметров (метод максимального правдоподобия), доверительные интервалы, критерии (t-тест, F-тест, χ²).

- **Теория групп и колец:** определения групп, полей, кольцо, примеры (Z, матрицы); гомоморфизмы, фактормодули.

- **Теория меры и интеграл Лебега:** σ-алгебры, измеримые функции, Лебегова мера; интеграл как обобщение сумм, теоремы о мажорированном, монотонном пределе.

- **Комплексный анализ:** аналитические функции, Cauchy-Riemann, контурные интегралы, теорема Коши, вычеты, примеры вычислений интегралов по контуру.

- **Функциональный анализ:** банаховы/гильбертовы пространства, операторы, собственные значения (теорема спектра для компактных операторов и самосопряжённых), примеры (фурье-преобразование как унитарный оператор).

- **Дифференциальная геометрия:** многообразия, тензоры, метрический тензор, ковариантная производная, геодезические, кривизна. Кратко: нужна для ОТО и геометрического тензорного анализа (γ^μ как пример).

- **Обобщённые функции (распределения):** δ-функция, слабая производная, свёртки. Использование: формулировка фундаментальных решений линейных операторов, пробки поведения решений.

- **Функциональные производные:** из вариационного исчисления: если \(S[\phi]=\int \mathcal{L}(\phi,\partial\phi)\,d^4x\), уравнение \(\delta S/\delta\phi=0\) даёт уравнение Эйлера–Лагранжа (в частности, уравнение Клейна–Гордона или Дирака).

- **Квантовая механика / QFT:** Гильбертовы пространства, базис собственных состояний, операторы \( \hat{H}|\psi\rangle = E|\psi\rangle \). Функциональный интеграл: 
\[
\mathcal{Z}[J] = \int \mathcal{D}\phi\, e^{i\int d^4x\,(\mathcal{L}(\phi) + J\phi)}.
\]
Здесь \(\mathcal{D}\phi\) формально — мера интегрирования по функциям (см. выше), \(\gamma^\mu\) — матрицы Дирака (в тензорном/матричном формализме).  

- **Стохастический анализ:** броуновское движение, интеграл Итô, СТОХАСТИЧЕСКИЕ ДИФФУРЫ, пример Блэка–Шоулза.
